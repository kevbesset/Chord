STRUCTURE

Task

A unit of asynchronous work. A task runs concurrently with the rest of the program, inherits the priority and task-local values of its context, and can be cancelled cooperatively.

let handle = Task(priority: .userInitiated) {
try await sidebar.collapse(animated: true)
}
await handle.value
